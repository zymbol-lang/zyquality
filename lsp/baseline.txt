# Disagreements between the language server and `zymbol check` that are correct.
#
# The two do not answer quite the same question. `zymbol check` analyses the
# file it was given; the LSP additionally RESOLVES the file's imports from disk
# and reports what it finds there, because an editor has the whole project in
# front of it and a command line does not. So on a fixture whose whole point is
# a bad import, the LSP says something and the CLI says nothing — and it is the
# LSP that is right.
#
# Everything below is that case. A file appearing here that is NOT an import
# fixture is a bug in one of the two.
#
# Format:  <path relative to zyquality/>  TAB  <kind>
#   LSP-ONLY   the LSP reports an error the CLI does not
#   CLI-ONLY   the CLI reports an error the LSP does not
#   WORDING    both report, with different text
#   NO-ANSWER  the LSP published no diagnostics at all
